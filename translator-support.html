Translator - Python Optic — Support

Translator is a live voice interpreter between English and Chinese. Open the app and talk: it listens to the conversation and speaks the translation aloud.

Getting the best result

For live cloud translation, add your own Google Gemini or OpenAI API key in the Setup screen (tap the gear icon). Without a key, the app uses on-device translation, which also works offline.

Allow microphone access when asked — the app cannot hear the conversation without it.
